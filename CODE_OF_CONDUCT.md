# Code of Conduct

## Our Pledge

We want this project to be a welcoming place for everyone, regardless of background, experience level, or identity.

## Expected Behaviour

- Be respectful and constructive in issues, pull requests, and discussions.
- Critique ideas and code, not people.
- Accept feedback gracefully and give it kindly.
- Credit others' work properly.

## Unacceptable Behaviour

- Harassment, insults, or personal attacks.
- Discriminatory language or imagery.
- Publishing others' private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Instances of unacceptable behaviour can be reported to the maintainer by opening a private report through GitHub or by contacting the maintainer via their GitHub profile. All reports will be reviewed and handled confidentially.

The maintainer may remove, edit, or reject comments, commits, code, issues, and other contributions that do not follow this Code of Conduct.
